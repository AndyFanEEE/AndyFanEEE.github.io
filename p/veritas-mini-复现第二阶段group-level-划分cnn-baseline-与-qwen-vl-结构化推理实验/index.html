VERITAS-MINI 复现第二阶段：group-level 划分、CNN baseline 与 Qwen-VL 结构化推理实验

Aug 21, 2026
阅读时长: 9 分钟

前言

这篇文章继续记录 VERITAS Deepfake 检测论文复现项目。上一篇主要完成了一个最小版本：用 HydraFake val 子集做 image-level 划分，训练 ResNet18 和 CLIP baseline，把基本流程跑通。

这一次我把实验目标往论文方向推进了一步：不再把旧的 veritas_mini 作为正式结果，而是重新构建了一个 group-level no-leakage split。简单说，同一个视频、同一个生成来源或同一个伪造组里的图片不能同时出现在 train / val / test 里。这个约束比随机 image-level 划分更严格，也更接近 VERITAS 论文关心的泛化评估。

本阶段仍然不是完整 VERITAS 训练级复现。我没有训练多模态大模型，也没有做 SFT、MiPO、P-GRPO。当前目标更现实：在有限算力和 API 预算下，验证两件事。

1
2

1. 常规视觉 baseline 在 no-leakage test split 上能做到什么程度；
2. VERITAS-style pattern-aware prompt 是否会改变 Qwen-VL 的 Deepfake 判断行为。

结果有点反直觉。CNN baseline 的整体指标更稳，Qwen-VL 的 VERITAS-style prompt 没有带来更高 accuracy，但它明显改变了模型的判断倾向：fake recall 大幅上升，real recall 几乎崩掉。

这正好说明了 prompt-level reproduction 的价值和边界。

相比上一篇 image-level split 上 84% 左右的 ResNet18 结果，这次降到了 74.3%。这很正常，因为 group-level split 减少了相似来源泄漏，测试集更难。

这个结果也提醒我：如果只看随机 image-level 划分，很容易高估模型能力。

ResNet50 比 ResNet18 略好，accuracy 提升到 75.0%。不过它也更偏向 fake：fake recall 从 ResNet18 的 76.0% 提升到 83.3%，real recall 从 72.7% 下降到 66.7%。

这说明模型容量变大后，确实学到了一些更敏感的伪造线索，但也带来了更多 real 被误判为 fake 的情况。

这个结果给后面的 Qwen-VL 实验提供了一个参照：如果多模态大模型只靠 prompt，不经过任务训练，它能不能比 CNN 更稳？

答案是：不能。

但它改变了模型的判断方式。

这个结果不能简单说好，也不能简单说差。

从格式上看，prompt 工程是成功的。format_valid_rate = 0.993322，unknown_count = 0，说明模型基本能稳定输出指定结构，也能给出明确的 real / fake 答案。

但从分类上看，模型出现了严重的 fake-biased tendency。它对 fake 很敏感，299 张有效 fake 中有 281 张被识别出来，fake recall 达到 93.98%。问题是它把 300 张 real 里的 278 张也判成 fake，real recall 只有 7.33%。

也就是说，VERITAS-style prompt 确实让 Qwen-VL 更像一个“取证检查者”，但它没有学会校准怀疑程度。

这个结果非常关键。

普通 prompt 和 CoT prompt 下，Qwen-VL 更偏向 real。尤其是 CoT，虽然让模型“逐步分析”，但它反而更保守，50 张 fake 里只识别出 5 张。

VERITAS-style prompt 则完全相反。它通过 <fast>、<planning>、<reasoning>、<reflection>、<conclusion> 这种结构，把模型推向更强的伪造怀疑模式。fake recall 从 basic 的 26% 和 CoT 的 10% 提升到 96%，但 real recall 从 94% / 98% 掉到 6%。

这说明 pattern-aware prompt 不是简单提升准确率，而是在改变模型的判断行为。

核心发现

这次实验最重要的发现不是哪个模型 accuracy 最高，而是不同方法的判断倾向不同。

1. group-level split 让任务更真实

旧的 image-level 最小复现中，ResNet18 可以达到 84% 左右的 test accuracy。换成 group-level no-leakage split 后，ResNet18 降到 74.3%，ResNet50 也只有 75.0%。

这说明严格划分会明显提高任务难度。对 Deepfake 检测来说，这种差异很重要。

2. CNN baseline 仍然最稳

ResNet50 是当前整体指标最好的模型：

1
2

accuracy = 0.7500
macro_f1 = 0.7483

它没有 Qwen-VL 那么高的 fake recall，但 fake / real 两类相对平衡。

3. CLIP frozen feature 不如 CNN 微调

CLIP + Logistic Regression 的 accuracy 是 66.8%。这说明通用视觉语义特征并不天然适合 Deepfake 检测。Deepfake 检测更依赖细粒度局部模式，而不是“这张图像语义上是什么”。

4. VERITAS-style prompt 改变了 Qwen-VL 的行为

Qwen-VL 在 basic / CoT 下明显偏 real，在 VERITAS-style 下明显偏 fake。

这正好对应 VERITAS 论文里的一个核心直觉：模型不应该只给出标签，而应该围绕伪造模式进行检查和反思。

但当前结果也暴露了 prompt-only 方法的问题。没有 SFT、MiPO、P-GRPO 训练校准时，模型会过度怀疑伪造，导致 real 被大量误判。

它能验证 pattern-aware reasoning 会影响模型判断行为，但不能复现 VERITAS 论文中的完整性能。

踩坑记录

坑一：不能只看 image-level split

最小复现阶段的结果看起来更好，但那只是入门实验。正式报告必须切换到 group-level no-leakage split，否则结果容易偏乐观。

这也是这次重新生成 data/veritas_full 的原因。

坑二：prompt 约束能稳定格式，但不能保证判断正确

VERITAS-style prompt 的格式合规率接近 99.3%，说明 XML-like 输出约束有效。

但格式稳定不等于判断稳定。模型很听话地输出了 <fast>、<planning>、<reasoning>、<reflection>、<conclusion>、<answer>，却把大量 real 判成 fake。

这个现象很适合写进报告：prompt 工程解决的是输出结构问题，不是模型能力和校准问题。

坑三：CoT 不一定有帮助

在 balanced100 上，CoT 的 fake recall 只有 10%，比 basic 的 26% 还低。

这说明“让模型一步步分析”不一定能提升 Deepfake 检测。没有针对任务训练时，CoT 可能只是让模型更认真地解释自己原本的偏见。

坑四：API 实验要保留 raw output

Qwen-VL 实验中保存了完整 raw output，这一点很有用。后面可以分析模型为什么把 real 判成 fake，是不是因为它把正常压缩痕迹、模糊背景、皮肤平滑都解释成伪造线索。

总结

这次复现阶段可以总结成三句话。

第一，veritas_full 的 group-level no-leakage split 让实验更接近正式评估。CNN baseline 的结果从之前的高分下降到 75% 左右，这是更可信的结果。

第二，传统视觉模型目前仍然更稳。ResNet50 在完整 test split 上取得：

1
2

accuracy = 0.7500
macro_f1 = 0.7483

第三，Qwen-VL 的 VERITAS-style prompt 没有提升整体 accuracy，但显著改变了判断行为。它把模型从 basic / CoT 下的 real-biased 推向 fake-biased，使 fake recall 提升到 93.98%，但 real recall 降到 7.33%。

这说明 prompt-level reproduction 能复现 pattern-aware reasoning 的行为影响，但不能复现论文完整性能。VERITAS 论文中的 SFT、MiPO、P-GRPO 不是可有可无的装饰，而可能正是让模型从“会怀疑”变成“会判断”的关键。

后续计划

后续我会继续做三件事。

一是整理错误案例，重点看 Qwen-VL 为什么把 real 判成 fake。这个分析比单纯提高 accuracy 更有价值。

二是把 CNN、CLIP、Qwen-VL 的结果整理成课程报告表格，明确区分 exploratory split 和 formal no-leakage split。

三是如果资源允许，再考虑更接近 VERITAS 原论文的训练阶段。但在当前阶段，不会直接声称完整复现 VERITAS。

当前结论很清楚：

1
2

有限资源下，prompt-level VERITAS-style reproduction 可以观察到 reasoning structure 对模型判断行为的影响；
但如果要达到论文级别的稳定性能，仍然需要训练和偏好优化。
